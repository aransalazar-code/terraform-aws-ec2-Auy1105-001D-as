# Módulo de Cómputo AWS - EC2

## Objetivos del repositorio
Gestionar y desplegar de manera automatizada instancias de cómputo EC2 parametrizadas en AWS.

## Propósito general del código Terraform
Proveer un componente de cómputo aislado y reutilizable que reciba de manera dinámica el ID de la subnet y el grupo de seguridad para levantar la máquina virtual.

## Instrucciones básicas de uso
Este módulo es invocado de manera remota desde el orquestador principal.
